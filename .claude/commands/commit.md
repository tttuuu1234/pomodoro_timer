変更内容を確認し、適切なコミットメッセージでコミットしてください。

手順:
1. `git status` と `git diff`（ステージ済み・未ステージ両方）で変更内容を確認
2. `git log --oneline -10` で直近のコミットメッセージのスタイルを確認
3. 変更内容を分析し、簡潔で的確なコミットメッセージを作成
4. 関連するファイルを `git add` でステージング（.envや認証情報ファイルは除外）
5. コミットを実行

コミットメッセージの規則:
- 日本語で記述
- 1行目は変更の要約（50文字以内目安）
- 必要に応じて空行を挟んで詳細を記述
- 末尾に `Co-Authored-By: Claude Opus 4.6 <noreply@anthropic.com>` を付与
